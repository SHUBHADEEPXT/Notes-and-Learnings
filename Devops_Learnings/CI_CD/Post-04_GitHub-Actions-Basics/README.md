# 🐙 CI/CD Day 4/7: GitHub Actions Starter File

GitHub Actions is powerful — but you don’t need complexity to get started.

---

## ✅ What This Workflow Does

- Triggers on every `push`
- Checks out your code 
- Installs dependencies 
- Runs tests (Node.js / Python / Java etc.)

---

## 📄 File: `.github/workflows/ci.yml`

### 🧠 Where to Save

Save this file in: .yarn/github/workflows/ci.yml

---

## 🛠️ Pro Tips

✅ Use on: [pull_request] for PR-based triggers
✅ Separate jobs for build, test, deploy
✅ Store secrets in GitHub Settings → Secrets

---

## 🔍 What You Can Add Later

- SonarQube for code analysis
- Docker image build + push
- Deployment to Kubernetes
